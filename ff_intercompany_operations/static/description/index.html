Intercompany Operations

By Flous Flow · Support

One Odoo 20 application for controlled intercompany Sales, Purchase, and Accounting synchronization between legal companies.

What is included

  • Quick Setup for source and destination companies, counterparties, and document direction.
  • Sales Order → Purchase Order and Purchase Order → Sales Order synchronization.
  • Posted customer invoice or credit note → draft vendor bill or credit note synchronization.
  • Draft-first policies, optional commercial-counterpart confirmation, and durable event tracking.
  • Manual synchronization and manager approval for controlled operations.
  • Agreement date windows, authorized administrators, and destination-company agreed pricing.
  • Explicit counterparty mapping with a visible Intercompany Counterparty badge.
  • Multi-company security, idempotency protection, Arabic translations, and operational links.

Recommended rollout

  1. Create the two legal companies and their intercompany contact mappings.
  2. Start with Create a Draft and verify products, warehouses, journals, currencies, and taxes.
  3. Test one Sales Order → Purchase Order flow in a staging database.
  4. Only then enable automatic confirmation for approved users.

Quick setup

Choose the source and destination companies, select the direction, and keep the default document action as Create a Draft until the workflow is approved.

Configuration guidance

Each agreement is explicit: the counterpart contact, direction, date window, document action, pricing policy, and authorized users are visible before activation.

Scope

This release creates controlled counterpart documents and accounting documents. Payments, reconciliation, receipt validation, and stock movement automation are intentionally outside this release.
